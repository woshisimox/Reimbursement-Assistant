# Reimbursement-Assistant

基于 Next.js 的智能报销助手，支持上传多种发票（住宿、打车、飞机、火车、餐饮等），通过 OCR 识别关键信息并自动按照行程顺序整理报销材料。

## 功能
- 支持拖拽/多文件上传图片或 PDF 发票
- 后端使用 `tesseract.js` 进行 OCR 识别，提取金额、日期和票据文本
- 依据票据类别自动排序：出发 → 住宿 → 当地交通 → 餐饮 → 返程
- 智能缺失提醒（例如仅有返程机票时提示补齐去程机票）
- 对未识别金额或日期的发票提示人工确认
- 生成可直接粘贴给外部大模型的“AI 指令”，用于在 OCR 失败时让云端 AI 代为整理报销

## 本地运行
```bash
npm install
npm run dev
```

启动后访问 <http://localhost:3000> 即可体验上传与行程整理。
